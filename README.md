# Postify Cursor Plugin

The official Postify Model Context Protocol (MCP) plugin for Cursor. This plugin connects Cursor's AI Agent directly to your Postify workspace.

## Features
* **Read & Draft:** Quickly summarize drafts or generate new posts without leaving your IDE.
* **Security Auditing:** Ask Cursor to list all active AI sessions connected to your account.
* **Secure OAuth:** Connects securely via WorkOS AuthKit using strict PKCE flows.

## How to use
Once installed from the Cursor Marketplace, simply ask Cursor's Agent to interact with your workspace:
> "Check my Postify profiles for recent analytics."
> "Create a new post on Postify for my linked profiles announcing our new feature."
